# ISO/IEC 8211 Parsing Library

This library implements the **ISO/IEC 8211** binary container format used by IHO S-57 Electronic Navigational Charts.

## ISO 8211 File Structure

An ISO 8211 file consists of:
1. **One DDR (Data Descriptive Record)** — defines the schema (field tags, subfield names, and formats)
2. **One or more Data Records** — contain actual field data, parsed according to the DDR

### Record Layout
Each record starts with a 24-byte **Record Leader** containing:
- Record length, interchange level, leader identifier
- Field area start offset
- Entry map (sizes of tag, length, and position fields in directory entries)

Following the leader is a **Directory** of entries, each specifying:
- Field tag (e.g., `"DSID"`, `"FRID"`, `"SG2D"`)
- Field length and starting position within the record's field area

### DDR Field Definitions
The DDR's fields define the schema for corresponding fields in data records. Each DDR field contains:
- **Data Structure Code** — `Iso8211DataStructureCode` (elementary, vector, array, concatenated)
- **Data Type Code** — `Iso8211DataTypeCode` (character string, implicit point, explicit point, binary)
- **Subfield definitions** — name/format pairs parsed from the DDR field controls

### Subfield Formats
Subfield format codes determine how to read binary data:

| Code | Meaning | Notes |
|------|---------|-------|
| `A` or `A(n)` | ASCII character data | Variable-length (delimited) or fixed-width |
| `I(n)` | Integer as ASCII digits | Fixed-width ASCII integer |
| `R(n)` | Real number as ASCII | Fixed-width ASCII real |
| `b11` | Unsigned 8-bit integer | 1 byte |
| `b12` | Unsigned 16-bit integer | 2 bytes, little-endian |
| `b14` | Unsigned 32-bit integer | 4 bytes, little-endian |
| `b21` | Signed 8-bit integer | 1 byte |
| `b22` | Signed 16-bit integer | 2 bytes, little-endian |
| `b24` | Signed 32-bit integer | 4 bytes, little-endian |

### Delimiters
- **Unit Terminator (UT)**: `0x1F` — separates subfields in variable-length data
- **Field Terminator (FT)**: `0x1E` — marks end of a field's data

### Repeating Groups
A `*` prefix in a DDR format descriptor indicates that the following subfields form a repeating group (e.g., coordinate arrays in SG2D/SG3D fields).

## Key Types

| Type | Role |
|------|------|
| `Iso8211DocumentReader` | Top-level entry point — reads a complete ISO 8211 file into an `Iso8211Document` |
| `Iso8211DataDescriptiveRecordReader` | Parses the DDR into `Iso8211DataDescriptiveRecord` with field definitions |
| `Iso8211FieldReader` | Reads subfield values from a data record field using its DDR field definition |
| `Iso8211FieldDefinition` | DDR-derived schema for a field (tag, name, subfield definitions) |
| `Iso8211SubfieldDefinition` | Name + `Iso8211SubfieldFormat` for a single subfield |
| `Iso8211SubfieldFormat` | Format type (`Iso8211SubfieldFormatType`) + width |
| `Iso8211RecordLeader` | Parsed 24-byte record leader |
| `Iso8211Record` | A data record containing an array of `Iso8211Field` entries |
| `Iso8211Field` | A single field within a record (tag + raw data bytes) |

## Conventions

- Use `ReadOnlySpan<byte>` for parsing operations where possible to avoid allocations.
- Binary integers in S-57 ISO 8211 files are **little-endian**.
- The library is internal to the solution; public API is exposed via `EncDotNet.Enc`.
