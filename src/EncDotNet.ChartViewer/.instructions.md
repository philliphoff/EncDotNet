# Chart Viewer — Avalonia/Mapsui Desktop Application

This project renders IHO S-57 Electronic Navigational Chart data on an interactive Mapsui map using Avalonia UI.

## Standards Reference

When working on chart rendering, layer ordering, feature symbology, or geometry construction, consult:

- `standards/md/S57v31.md` — Part 3 clauses 4–5 (feature and spatial record coding conventions) for understanding how features reference geometry
- `standards/md/S57v31AppendixACh1.md` — Object class definitions (which geometric primitives each object supports)
- `standards/md/S57v31AppendixB1AnnexA.md` — ENC Product Specification (display-related encoding rules, mandatory display objects)
