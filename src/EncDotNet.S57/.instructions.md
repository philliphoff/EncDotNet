# S-57 Domain Model Library

This library models IHO S-57 Electronic Navigational Chart data, built on top of the `EncDotNet.Iso8211` parser.

## Layered Abstraction

The library provides two levels of abstraction:

1. **`S57Document` / `S57DocumentReader`** — direct mapping from ISO 8211 records to S-57 typed records (`S57FeatureRecord`, `S57VectorRecord`). All records are flat with RCNM/RCID-based identity.
2. **`S57Chart` (in `Charts/`)** — higher-level model that classifies spatial records into `S57IsolatedNode`, `S57ConnectedNode`, `S57Edge`, and `S57Face`, and features into `S57PointFeature`, `S57LineFeature`, `S57AreaFeature`, and `S57MetaFeature`. Records are indexed by `S57RecordName` in immutable dictionaries.

## Record Types

### Feature Records (`S57FeatureRecord`, RCNM=100)
Each feature has:
- **OBJL** (`S57ObjectCode`) — the type of real-world object (e.g., DEPARE=42, SOUNDG=129, LIGHTS=75)
- **PRIM** (`S57GeometricPrimitive`) — Point, Line, Area, or None
- **GRUP** — group code (1=skin of the earth, 2=all others)
- **Attributes** (`ImmutableArray<S57AttributeValue>`) — ATTL/ATVL pairs from ATTF and NATF fields
- **Spatial pointers** (`ImmutableArray<S57SpatialPointer>`) — FSPT references to vector geometry
- **Feature pointers** (`ImmutableArray<S57FeaturePointer>`) — FFPT references to related features

### Spatial Records (`S57VectorRecord`)
Identified by RCNM:
- **Isolated Node (110)** — single point or sounding cluster; has SG2D (position) or SG3D (soundings), not both
- **Connected Node (120)** — topology node at an edge endpoint; has a single SG2D position
- **Edge (130)** — polyline geometry with SG2D intermediate coordinates; references beginning/end connected nodes and left/right faces via VRPT
- **Face (140)** — area bounded by edges; references edges via VRPT with USAG (exterior/interior) and ORNT (forward/reverse)

## Topology (Chain-Node Model)

S-57 uses chain-node topology for area geometry:

```
Feature (PRIM=Area) —[FSPT]→ Face —[VRPT]→ Edge —[VRPT]→ Connected Node
                                                    ↓
                                              SG2D coordinates
```

- **Area features** reference one or more **Faces** via FSPT
- **Faces** reference **Edges** via VRPT, with:
  - `USAG` = Exterior (1) or Interior (2) to distinguish outer boundary from holes
  - `ORNT` = Forward (1) or Reverse (2) to indicate edge traversal direction
- **Edges** reference their **beginning and end Connected Nodes** via VRPT with `TOPI` = Beginning (1) or End (2)
- **Edges** also reference **left and right Faces** via VRPT with `TOPI` = LeftFace (3) or RightFace (4)

To build area geometry, assemble edge coordinates respecting orientation, grouping by usage indicator.

## Coordinate System

- Raw coordinates are **integers** stored in SG2D (Y=latitude, X=longitude) and SG3D (Y, X, depth)
- Divide by **COMF** (`S57DataSetParameters.CoordinateMultiplicationFactor`, typically 10,000,000) to get decimal degrees
- Divide sounding depth by **SOMF** (`S57DataSetParameters.SoundingMultiplicationFactor`, typically 10)
- Use `S57Chart.ToDecimalDegrees()` and `S57Chart.ToDepth()` for conversion

## Catalogs (`Catalogs/`)

- **CATALOG.031** is an ISO 8211 file containing **CATD** records that list chart files in an exchange set
- `S57CatalogReader` parses CATALOG.031 into `S57Catalog` (a collection of `S57CatalogEntry`)
- Each `S57CatalogEntry` has: file name, geographic bounds (SLAT/NLAT/WLON/ELON), implementation type, CRC

## Key Constants

- **`S57FieldTags`** — string constants for ISO 8211 field tags (DSID, FRID, VRID, SG2D, etc.)
- **`S57SubfieldNames`** — string constants for subfield labels (RCNM, OBJL, COMF, XCOO, YCOO, etc.)
- **`S57ObjectCode`** — enum mapping S-57 Appendix A object class names to their OBJL integer codes
- **`S57RecordNameCodes`** — integer constants for RCNM values (100=Feature, 110=IsolatedNode, etc.)

## Conventions

- All parsed data uses `ImmutableArray<T>` and `ImmutableDictionary<K,V>` — records are immutable after construction.
- `S57RecordName` (a `readonly record struct`) is the primary key for looking up records.
- Feature attributes use numeric ATTL codes from S-57 Appendix B; values (ATVL) are strings that may represent enumerations, floats, or coded values.
