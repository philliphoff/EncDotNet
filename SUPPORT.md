# Support

This page explains where to go for help with EncDotNet.

## Questions and discussion

For "how do I...?" questions, usage help and ideas, ask on the project
[Discord](https://discord.gg/kf6B9EZqqB). Before you ask, check:

- The [documentation](docs/index.md), including the package READMEs under
  `src/<project>/`.
- Existing [issues](https://github.com/philliphoff/EncDotNet/issues), in case
  your question has been answered.

## Bugs and feature requests

- Found a bug? Open a
  [bug report](https://github.com/philliphoff/EncDotNet/issues/new?template=bug_report.yml).
- Want a feature? Open a
  [feature request](https://github.com/philliphoff/EncDotNet/issues/new?template=feature_request.yml).

Include the package version, your platform, and the smallest way to reproduce
the problem. Don't attach real ENC cells; describe the data, name a public
NOAA cell, or attach a small synthetic file.

## Security issues

Don't report security vulnerabilities as public issues. Follow the private
process in [SECURITY.md](SECURITY.md).

## Contributing

To contribute code or docs, see [CONTRIBUTING.md](CONTRIBUTING.md).
